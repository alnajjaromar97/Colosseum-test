# Gaming Center Android — نسخة أولية

## نوع المشروع
مشروع Android Studio أصلي (Java) يثبت كتطبيق أندرويد، وليس تطبيق Windows.

## تشغيل وبناء APK
1. افتح Android Studio على كمبيوتر.
2. اختر Open وافتح مجلد `gaming_center_android`.
3. انتظر Gradle Sync، وثبّت Android SDK 35 إذا طُلب.
4. من Build اختر Build APK(s).
5. عادةً تجد APK في `app/build/outputs/apk/debug/app-debug.apk`.
6. انقل APK إلى هاتف Android وثبّته بعد السماح بالتثبيت من هذا المصدر.

## بيانات الدخول التجريبية
- المستخدم: `admin`
- كلمة المرور: `ChangeMe123!`

## الموجود
- قاعدة بيانات SQLite محلية دائمة على الهاتف.
- 54 جهاز PC و4 طاولات PlayStation.
- بدء وإنهاء الجلسات، زبائن، منتجات ومخزون، طلبات مسجلة، حسابات موظفين.
- تصميم داكن ملائم للأندرويد.

## حدود النسخة الحالية
هذه نسخة تجريبية محلية على جهاز Android واحد. كلمة المرور محفوظة كنص واضح في النسخة التجريبية؛ لا تستخدم بيانات حقيقية أو تنشرها تجارياً قبل إضافة تجزئة كلمات المرور، إدارة جلسات الدخول، صلاحيات دقيقة، نسخ احتياطي وتشفير مناسب.
واجهة طلبات الزبائن من أجهزة PC، مزامنة عدة أجهزة عبر شبكة المحل، الفوترة والمدفوعات الكاملة، والتطبيق العميل الذي يقفل أجهزة Windows تلقائياً لم تُستكمل بعد. قفل Windows لا يمكن أن ينفذه تطبيق أندرويد وحده؛ يحتاج خادماً محلياً وعميل Windows مثبتاً ومختبراً على أجهزة المحل.
